# Handbook Dependra

Рабочие процессные документы. Не смешивать с продуктовой спекой в [`docs/`](../docs/README.md).

Версия пакета: **0.0.1** (не повышать на этом этапе).

## Состав

| Раздел | Назначение |
|--------|------------|
| [`adr/`](adr/README.md) | Журнал архитектурных решений |
| [`roadmap/`](roadmap/README.md) | Полный roadmap S01–S10, backlog, TODO-чеклист |
| [`context/`](context/README.md) | Постоянный контекст проекта |

## Правила обновления

- **ADR** — новая запись только при важном решении; мелкие правки кода без ADR.
- **Roadmap** — статусы задач обновляются по ходу работы; смена порядка — с осознанием зависимостей.
- **Context** — не лог переписки; обновление содержимого только после подтверждения владельцем.
