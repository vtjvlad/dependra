# Шаблон задачи

## Схема ID

| Уровень | Формат | Пример |
|---------|--------|--------|
| Большой этап | `S01`…`S10` | `S01` |
| Подэтап | `S0N-A`, `S0N-B`… | `S01-A` |
| Задача этапа S01 | `MVP-0xx` (legacy) | `MVP-001` |
| Задача этапов S02+ | `S0N-xxx` | `S02-001` |

## Шаблон

```markdown
## S0N-xxx: Название

- **id:** S0N-xxx   # или MVP-0xx для этапа S01
- **stage:** S0N
- **подэтап:** S0N-A | S0N-B | …
- **приоритет:** высокий | средний | низкий
- **dependsOn:** S0N-yyy, MVP-00Y, …
- **статус:** запланировано | ожидает подтверждения | в работе | завершено | отложено | отменено
- **спека:** ссылка на docs/… (или blueprint до promote)
- **описание:** что сделать
- **результат:** как проверить (AC)
```

Для задач S01 допускается краткая табличная форма в [mvp-backlog.md](mvp-backlog.md) без полного блока выше.
