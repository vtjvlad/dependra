# Исследование окружения файла

## Исследование окружения файла ( -P)
Определять:
* символические ссылки;
* hard links;
* ярлыки;
* алиасы;
* bash-скрипты;
* shell-скрипты;
* cron-задачи (если доступны);
* сценарии, в которых используется файл;
* возможные точки входа.
Выводить их расположение.
