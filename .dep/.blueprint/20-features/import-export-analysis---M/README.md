# Анализ импортов и экспортов

## Анализ импортов и экспортов( -M)
Для поддерживаемых языков выполнять полноценный AST-анализ.
Не использовать регулярные выражения.
Определять:
импорты;
экспорты;
относительные пути;
абсолютные пути;
динамические импорты;
реэкспорты.
