# Дополнительная информация о файле

## Дополнительная информация ( -B)
Выводить:
* абсолютный путь;
* относительный путь;
* права доступа;
* права пользователя;
* требуется ли sudo/root:
* чтение;
* запись;
* изменение;
* удаление.
Определять наличие копий файла.
Копии определять не только по имени.
Необходимо учитывать:
* размер;
* первые строки;
* контрольную сумму;
* степень совпадения содержимого.
Если совпадение небольшое — файл копией не считать.
Выводить расположение найденных копий.
