# Анализ зависимостей запуска

## Анализ зависимостей запуска ( -U)
Определять способ выполнения файла.
Если язык компилируемый:
определять:
* компилятор;
* систему сборки;
* необходимые инструменты.
Например:
gcc
clang
javac
cargo
go
dotnet
Если язык интерпретируемый:
определять:
* Node.js;
* Python;
* Lua;
* PHP;
* Ruby;
* Bash;
* другие интерпретаторы.
