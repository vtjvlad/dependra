# Анализ качества кода

## Анализ качества кода ( -F)
На первом этапе реализовать только общие показатели.
Например:
процент комментариев;
процент неиспользуемых переменных;
примерная оценка качества кода;
примерная оценка оформления;
количество пустых строк;
количество лишних пустых строк;
дублирование кода;
подозрительные конструкции;
синтаксические ошибки;
логические предупреждения.
Без подробного объяснения каждой ошибки.
