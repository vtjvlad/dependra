# Отображение зависимостей

## Отображение зависимостей ( -M)
Выводить две колонки.
Слева:
Файлы, которые импортируют текущий файл.
Справа:
Файлы, из которых импортирует текущий файл.
Предусмотреть режимы:
* только имя файла;
* относительный путь;
* абсолютный путь.
