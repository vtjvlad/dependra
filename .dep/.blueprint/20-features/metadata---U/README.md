# Метаданные

## Метаданные ( -U)
При наличии выводить:
* EXIF;
* служебные данные;
* встроенную metadata;
* информацию компилятора;
* дополнительные атрибуты файловой системы.
Архитектура должна позволять подключать новые извлекатели метаданных.
