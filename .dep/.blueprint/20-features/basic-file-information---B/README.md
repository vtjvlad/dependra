# Базовая информация о файле

## Базовая информация о файле( -B)
Выводить:
* имя файла;
* расширение;
* формат;
* MIME-тип;
* размер;
* дата создания;
* дата изменения;
* дата последнего доступа;
* владелец;
* группа;
* язык программирования;
* используемый движок;
* тип файла.
