# Экспортируемые сущности

## Экспортируемые сущности ( -M)

Показывать:
* экспортируемые функции;
* импортируемые функции;
* экспортируемые классы;
* импортируемые классы;
* экспортируемые переменные;
* импортируемые переменные;
* экспортируемые типы (при поддержке языка);
* импортируемые типы

Во всех вариантах отображения:
- только имя;
- относительный путь;
- абсолютный путь.
