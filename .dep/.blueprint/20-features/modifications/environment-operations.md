# Работа с окружением

Возможные операции

На текущий момент архитектура должна предусматривать возможность реализации следующих операций.

Работа с окружением

* установка отсутствующих системных зависимостей;
* установка необходимых пакетов через пакетные менеджеры операционной системы;
* установка отсутствующих npm-пакетов;
* установка зависимостей других экосистем (при необходимости).

Например:

* apt;
* pkg;
* dnf;
* pacman;
* zypper;
* apk;
* brew;
* winget;
* cargo;
* snap;
* flatpak;
* npm;
* pnpm;
* yarn;
* bun;
* pip;
* gem;
* и других.
