# Семантическая модель (Semantic Model)

Семантическая модель (Semantic Model)
Внутреннее представление смысловых связей проекта. Она описывает не только синтаксическую структуру программы, но и смысл объектов, их роли, зависимости, области видимости, отношения между символами и контекст использования.
Семантическая модель объединяет информацию, полученную из различных источников анализа, включая AST, LSP и другие специализированные инструменты.
Семантическая модель служит промежуточным слоем между исходными данными анализа и Единой модели проекта. Она особенно важна для точного определения связей между модулями, импортами, экспортами и символами.
