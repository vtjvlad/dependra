# Инкрементальная сборка

## Инкрементальная сборка

Build System отслеживает изменения файлов.
При повторной сборке пересобираются только изменённые пакеты и их зависимые компоненты.
Например:
packages/logger

↓

packages/core

↓

apps/cli
Если изменён только logger, остальные независимые пакеты не пересобираются.
