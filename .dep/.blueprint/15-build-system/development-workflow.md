# Development Workflow

## Development Workflow. 
Именно он есть у Neovim, LLVM, Rust, Zig, Deno и других крупных проектов. В нём описывается, как разработчик собирает проект локально и как происходит цикл разработки:
git clone

↓

bootstrap

↓

install dependencies

↓

build

↓

run tests

↓

run cli

↓

modify code

↓

incremental rebuild

↓

commit

↓

CI

↓

release
