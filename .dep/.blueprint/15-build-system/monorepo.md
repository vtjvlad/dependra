# Монорепозиторий

## Монорепозиторий

Все пакеты проекта находятся в едином монорепозитории.
Каждый пакет имеет собственные:
* зависимости;
* тесты;
* документацию;
* конфигурацию;
* версию (при необходимости).
Общие зависимости управляются централизованно.
