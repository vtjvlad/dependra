# Система релизов

## Система релизов
Релиз создаётся только после успешного выполнения полного графа сборки.
Процесс публикации включает:
Build

↓

Tests

↓

Verification

↓

Versioning

↓

Changelog

↓

Artifacts

↓

Publish
Каждый релиз должен быть воспроизводимым из исходного кода соответствующего тега.
