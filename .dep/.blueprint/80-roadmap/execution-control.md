# Контроль выполнения

Разработка проекта должна максимально строго следовать данному документу.

Переходить к следующему этапу запрещается без подтверждения владельца проекта.

Любые изменения порядка разработки должны сначала обсуждаться.

Cursor не должен самостоятельно менять порядок выполнения задач.

Если появляется новая идея, она добавляется в TODO и ожидает подтверждения.

Основная документация проекта не является частью данного TODO.
