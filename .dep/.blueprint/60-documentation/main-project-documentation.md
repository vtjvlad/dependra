# Основная документация проекта

1. Основная документация проекта

Поддерживается на двух языках:

* русский;
* английский.

Данная документация описывает проект полностью.

При ее написании необходимо исходить из того, что весь запланированный функционал уже реализован.

Она должна содержать максимально полное описание:

* назначения проекта;
* архитектуры;
* всех подсистем;
* всех предполагаемых возможностей;
* принципов работы;
* концепции проекта;
* внутренних механизмов.

При этом запрещается включать:

* команды CLI;
* флаги;
* инструкции по использованию;
* инструкции по установке;
* инструкции по интеграции;
* примеры использования.

Эта документация является архитектурной документацией проекта.

Она не зависит от текущего этапа реализации.
