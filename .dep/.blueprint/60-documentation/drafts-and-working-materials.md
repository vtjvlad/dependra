# Черновики

Черновики

Разрешается создавать любое количество:

* копий;
* черновиков;
* предложений;
* вариантов;
* временных документов.

Все подобные материалы должны храниться отдельно от основной документации.

При необходимости можно использовать отдельную директорию или отдельный репозиторий.

Никогда не смешивать черновики с основной документацией.
