# Неприкосновенность документации

Неприкосновенность

Основная документация запрещена для автоматического редактирования.

Изменения допускаются только вручную владельцем проекта.

Любые предложения по изменению должны оформляться исключительно в копиях или черновиках.

Никогда не изменять оригинал автоматически.
