# Публичная документация

2. Публичная документация

Отдельная документация.

Используется для публикации проекта.

Она должна содержать только реализованный функционал.

В нее входят:

* описание возможностей;
* примеры;
* команды;
* флаги;
* установка;
* использование;
* интеграция.

Она формируется постепенно.

Каждая новая версия соответствует определенному релизу проекта.

Например:

0.1.x

0.2.x

0.3.x

…

Публичная документация также считается неприкосновенной.

Автоматическое изменение запрещено.

Любые изменения сначала оформляются в копиях.
