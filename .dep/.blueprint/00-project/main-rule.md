# Главное правило

### Главное правило

Не реализовывать сразу весь функционал.
Сначала создать качественную архитектуру, независимые интерфейсы, систему модулей и расширяемую платформу.
Каждая новая возможность должна подключаться как отдельный модуль без изменения ядра системы.
