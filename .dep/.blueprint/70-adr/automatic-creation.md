# Автоматическое создание ADR

Автоматическое создание

Cursor не должен самостоятельно создавать ADR.

Перед созданием новой записи необходимо получить подтверждение владельца проекта.

После подтверждения Cursor должен подготовить черновик новой записи.

Финальная запись создается только после согласования.
