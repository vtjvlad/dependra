# Флаги CLI
Практически весь функционал должен включаться или отключаться флагами.
Например:
–basic
–extended
–metadata
–runtime
–permissions
–imports
–exports
–functions
–variables
–graph
–syntax
–quality
–json
–mermaid
–graphviz
–full
Архитектура должна позволять легко добавлять новые флаги.
