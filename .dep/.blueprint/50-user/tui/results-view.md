# Просмотр результатов

Просмотр результатов

TUI должен значительно улучшать читаемость выводимой информации.

Должны поддерживаться:

* сворачиваемые разделы;
* группировка данных;
* цветовое оформление;
* отображение зависимостей;
* древовидные структуры;
* таблицы;
* панели;
* карточки;
* различные режимы просмотра.
