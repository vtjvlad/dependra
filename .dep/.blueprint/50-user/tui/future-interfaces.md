# Дальнейшее развитие интерфейсов

Дальнейшее развитие

Архитектура должна предусматривать возможность появления в будущем дополнительных пользовательских интерфейсов.

Например:

* Web UI;
* Desktop GUI;
* REST API;
* библиотека для Node.js;
* интеграция с редакторами кода;
* плагины для IDE.

Все интерфейсы должны использовать единое ядро проекта и единое публичное API, не дублируя бизнес-логику и не создавая собственных реализаций анализа.


Добавление нового интерфейса не должно требовать изменения логики работы проекта.
