# Работа с выводом

Работа с выводом

TUI должен обеспечивать более удобное представление результатов анализа.

Например:

* древовидный просмотр;
* группировку данных;
* сворачиваемые разделы;
* фильтрацию;
* поиск;
* сортировку;
* быстрый переход между связанными объектами;
* навигацию по графу зависимостей;
* просмотр больших отчетов без необходимости повторного запуска анализа.
