# Использование искусственного интеллекта

- ## Использование искусственного интеллекта

Архитектура проекта должна предусматривать возможность интеграции решений, использующих искусственный интеллект.

Например:

* анализ качества кода;
* поиск потенциальных ошибок;
* интеллектуальный анализ зависимостей;
* генерация рекомендаций;
* объяснение результатов анализа;
* поиск архитектурных проблем.

Интеграция ИИ рассматривается исключительно как дополнительное расширение функциональности.

Все основные возможности проекта должны работать полностью автономно без использования AI-сервисов.

⸻

До появления объективной необходимости проект полностью разрабатывается на JavaScript!!!—
