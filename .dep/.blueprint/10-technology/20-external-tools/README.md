# Использование внешних инструментов

- ## Использование внешних инструментов

Использование готовых инструментов, библиотек и специализированных решений приветствуется.
Если они решают конкретную задачу значительно лучше собственной реализации .
Вероятно,  а главное это будет куда быстрее и производительнее.

В первую очередь это относится к узкоспециализированным областям, требующим сложного анализа исходного кода или взаимодействия с различными языками программирования.

Например:

* Tree-sitter;
* Language Server Protocol (LSP);
* готовые AST-парсеры;
* компиляторы;
* интерпретаторы;
* средства анализа кода;
* системы построения графов;
* специализированные библиотеки обработки файлов;
* другие профильные инструмент

Не следует реализовывать с нуля функциональность, для которой уже существуют зрелые, надежные и хорошо поддерживаемые решения.

При выборе инструмента необходимо оценивать:

* качество реализации;
* зрелость проекта;
* поддержку;
* производительность;
* удобство интеграции;
* возможность последующей замены без изменения архитектуры проекта!!!—
