# Использование интерпретируемых языков

- ## Использование интерпретируемых языков

При необходимости допускается использование других интерпретируемых языков для решения отдельных специализированных задач.

Например:

* Lua;
* Python;
* Ruby;
* Bash.

Подобные компоненты являются вспомогательными и используются только там, где это действительно упрощает реализацию или повышает качество решения.
