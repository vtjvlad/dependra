# Дополнение архитектуры с целью оптимизации

- ## Дополнение архитектуры с целью оптимизации

Архитектура должна позволять в будущем заменить любые вычислительно  тяжелые подсистемы на реализации на Rust Zig GoLang без изменения CLI.

Основная архитектура проекта должна предусматривать возможность последующего расширения отдельными высокопроизводительными компонентами.

Такие компоненты могут разрабатываться на других языках программирования исключительно в случаях, когда это действительно необходимо.

Основная цель подобных компонентов:

* увеличение производительности;
* ускорение вычислений;
* снижение потребления памяти;
* обработка больших объемов данных;
* оптимизация действительно ресурсоемких операций.

Подобные реализации допускаются только для узкоспециализированных задач, которые невозможно или нецелесообразно эффективно решить средствами интерпретируемых языков.

В качестве возможных языков могут использоваться:

* Rust;
* Zig;
* Go;
* OCaml;
* Elixir;
* C;
* C++;
* другие подходящие языки.

Использование подобных компонентов не является обязательным.
