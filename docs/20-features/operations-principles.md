# Принципы операций

## Цель

Пользовательский функционал — набор **независимых комбинируемых** операций (прежде всего анализ и отображение зависимостей).

## Правила

1. Любая операция выполняется:
   - отдельно;
   - совместно с другими;
   - как часть заранее определённого набора (профиль / level).
2. Операция не должна требовать включения несвязанных операций.
3. Общий контекст и модель проекта разделяются; побочные эффекты анализа на диск в MVP запрещены (read-only).

## Alias

В исходном материале встречается имя **fds** (File Dependency Scoper) как синоним идеи утилиты. Продуктовое имя — **Dependra**.

## Acceptance criteria

- [ ] CLI позволяет включать операции флагами независимо
- [ ] Инспекторы не жёстко связаны друг с другом в коде
