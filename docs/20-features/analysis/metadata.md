# Метаданные (−U, S05)

## Цель

Извлечь **расширенные метаданные** целевого файла через подключаемые extractors (провайдеры). Ядро не знает конкретные форматы (EXIF, compiler attrs, …) — только контракт провайдера и агрегацию результата.

## Границы

### Входит (S05)

- Инспектор `metadata` + реестр extractors
- Встроенные extractors (минимум для AC):
  - **fs-extended** — доп. FS-атрибуты сверх basic/additional (birthtime, blocks, inode — best-effort по платформе)
  - **embedded-text** — эвристика «встроенных» служебных маркеров в начале файла (shebang уже в runtime S04; здесь: `@license` / `fileoverview` / `generated by` в первых N строках комментариев — best-effort)
- Контракт провайдера: `id`, `supports(file)`, `extract(ctx) → { data, skipped? }`
- Возможность зарегистрировать новый extractor без правки инспектора (plugin-hook в `metadata/` / registry)
- CLI: `--metadata` / `-me`
- Text-секция `metadata`; JSON-ключ `metadata`

### Не входит

- Полноценный EXIF/IPTC для бинарных изображений (контракт готов; **реализация EXIF-extractor** — optional stub: `supports` → false для non-image или пустой data + note в `skippedProviders`)
- Compiler metadata для .class/.o (S09 / later)
- Замена basic (`-b`) и additional (`-a`) — metadata **дополняет**, не дублирует обязательные поля S01/S02
- Мутации файла / запись xattr

## CLI

| Long | Short | Правило short |
|------|-------|---------------|
| `--metadata` | `-me` | `-m` = `--mermaid` → вторая буква → `-me` |

Не в default-all.  
Спека: [s05-flags.md](../../50-cli/s05-flags.md).

## Инспектор

- id: `metadata`
- Ключ `results.metadata` только при `--metadata` / `-me`
- Prerequisites: файл существует; AST **не** обязателен (кроме extractors, которые сами запросят SourceFile)

## Вход

- `targetPath`
- `options.pathMode` — для путей в data (если extractor их отдаёт)
- Зарегистрированные metadata providers

## Выход (`data`)

```json
{
  "pathMode": "relative",
  "providers": [
    {
      "id": "fs-extended",
      "status": "ok",
      "data": {
        "ino": "123456",
        "nlink": 1,
        "blocks": 8,
        "birthtimeMs": 1710000000000,
        "atimeMs": 1710000001000,
        "mtimeMs": 1710000002000,
        "ctimeMs": 1710000002000
      }
    },
    {
      "id": "embedded-text",
      "status": "ok",
      "data": {
        "markers": [
          { "kind": "license", "value": "MIT", "loc": { "line": 1, "column": 0 } },
          { "kind": "fileoverview", "value": "App entry", "loc": { "line": 2, "column": 0 } }
        ]
      }
    }
  ],
  "skippedProviders": [
    {
      "id": "exif",
      "reason": "unsupported-type"
    }
  ]
}
```

### Поля

| Поле | Назначение |
|------|------------|
| `providers[]` | Успешно отработавшие extractors (`status: "ok"`) |
| `providers[].data` | Свободная схема **внутри** провайдера; стабильные id задокументированы здесь |
| `skippedProviders[]` | `supports===false` или мягкий skip (не ошибка инспектора) |

Если все провайдеры skipped и ни одного ok — всё равно `status: "ok"` инспектора, пустой `providers`, заполненный `skippedProviders` (файл просто «без метаданных»).

## Контракт extractor (S05)

```text
id: string
supports(sourceFileMeta): boolean
extract(context): { data: object } | { skip: true, reason: string }
```

- Ошибка extract (throw / I/O) → запись в `skippedProviders` с `reason: "extract-failed"` **или** (если провайдер помечен critical — в S05 таких нет) ошибка инспектора. Default: soft-fail.
- Регистрация: тот же registry pattern, что у inspectors (отдельный `metadataProviders` list).

## Text (schematic)

```
┌─ metadata ─────────────────────────────────────┐
│  fs-extended  ino … · birthtime …              │
│  embedded-text  license MIT · fileoverview …   │
│  skipped  exif (unsupported-type)              │
└────────────────────────────────────────────────┘
```

## Правила

1. Не дублировать обязательно поля basic (`size`, `mime`, …) и additional (`permissions`, `copies`) — ссылка «см. -b/-a» допустима только в text-подсказке, не в JSON-обязаловке.
2. Платформенные поля fs-extended: отсутствующее на OS → опустить ключ (не `null`-шум), либо `null` с документированием в AC фикстур Linux.
3. `embedded-text`: сканировать не более **40** первых строк; только comment/shebang-подобные линии.
4. EXIF-провайдер в S05 может быть зарегистрирован как stub (`supports` → false для `.js`).
5. Инспектор не знает `--level` / профили.

## Ошибки инспектора

| code | category | Условие |
|------|----------|---------|
| `FILE_NOT_FOUND` | validation | Нет целевого |
| `READ_FAILED` | execution | Не прочитать файл для extractors, которым нужно содержимое, **и** ни один provider не смог работать |

Мягкие skip провайдеров — не ошибка инспектора.
