# CLI flags (S08)

| Long | Short | Действие |
|------|-------|----------|
| `--tui` | `-t` | Запустить интерактивный TUI |
| (subcommand) | `tui` | То же: `dependra tui` |

Требуется TTY. Спека: [docs/50-tui/overview.md](../50-tui/overview.md).
