# CLI интерфейс (MVP)

## Цель

Минимальный командный интерфейс для запуска MVP-операций. Версия пакета: `0.0.1`.

## Синтаксис

```
dependra <file> [options]
```

Альтернатива до появления bin: `node src/cli/… <file> [options]` (детали реализации — в коде; контракт флагов — здесь).

## Флаги MVP

| Флаг | Действие |
|------|----------|
| `--basic` | Инспектор базовой информации (−B) |
| `--imports` | Анализ импортов |
| `--exports` | Анализ экспортов |
| `--graph` | Двуколоночные зависимости |
| `--json` | Вывод JSON вместо текста |
| `--path-mode <name\|relative\|absolute>` | Режим путей для graph (default: `relative`) |
| `--help` | Справка |
| `--version` | Версия пакета (`0.0.1`) |

Если не указан ни один из `--basic|--imports|--exports|--graph`, по умолчанию: **все MVP-операции** (basic + imports + exports + graph).

Комбинации флагов разрешены (принцип независимых операций).

## Вход

- `<file>` — обязательный путь к файлу
- `cwd` — `process.cwd()`

## Выход

См. [output-formats.md](output-formats.md).

## Коды выхода

| Code | Значение |
|------|----------|
| `0` | Успех (все запрошенные инспекторы `ok`) |
| `1` | Ошибка валидации CLI / нет файла |
| `2` | Хотя бы один запрошенный инспектор завершился `error` |
| `3` | Внутренняя ошибка CLI/ядра |

## Ошибки CLI

- Нет `<file>` → help + exit 1
- Неизвестный флаг → сообщение + exit 1
- Конфликт не предусмотрен для MVP-флагов
