# Глоссарий MVP

Краткие определения для текущего этапа. Полный архив терминов: [`.dep/.blueprint/99-terminology/`](../../.dep/.blueprint/99-terminology/README.md).

| Термин | Определение |
|--------|-------------|
| **Inspector** | Независимый модуль анализа одной области (базовый файл, импорты, зависимости и т.д.) |
| **Analyzer** | Компонент, выполняющий анализ поверх модели / AST |
| **Parser** | Модуль разбора исходника в AST / промежуточное представление |
| **AST** | Abstract Syntax Tree — дерево синтаксиса исходного файла |
| **SourceFile** | Сущность модели: путь, текст/метаданные, язык, представление |
| **Import** | Зафиксированная зависимость «этот файл импортирует X» |
| **Export** | Экспортируемая сущность или реэкспорт |
| **DependencyEdge** | Ребро графа зависимостей между файлами/модулями |
| **Project Model** | Единое внутреннее представление, общее для операций |
| **Pipeline** | Последовательность/композиция операций анализа |
| **Report** | Результат для пользователя (text / JSON) |
| **Operation** | Независимая комбинируемая пользовательская операция |
| **Module contract** | Публичный API + схемы входа/выхода + ошибки + версия интерфейса |
| **MVP-ядро** | Минимальный набор для этапа `0.0.1` (см. [mvp-scope](../20-features/mvp-scope.md)) |
| **Deferred** | Документировано, но вне текущего этапа реализации |
| **ADR** | Architecture Decision Record — запись решения в `handbook/adr/` |
| **Handbook** | Процессные документы: ADR, roadmap, context |

## Acceptance criteria

- [ ] Термины MVP однозначны и согласованы с architecture/features
- [ ] Нет противоречий с `inspector-contract` и `project-model`
