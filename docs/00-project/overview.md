# Обзор проекта

## Цель

Dependra — CLI-платформа для исследования файлов, проектов и исходного кода.

Главная цель: дать максимально полезную информацию о выбранном файле — окружение, зависимости, связи с другими файлами, особенности запуска и качество кода — через набор независимых инспекторов.

Работа строится по принципу: **каждый инспектор отвечает только за свою область**.

## Границы (текущий этап, 0.0.1)

### Входит (MVP-ядро)

- Анализ одного JS-файла (ESM / CJS) в Node.js
- Базовая информация о файле
- Импорты / экспорты (AST)
- Отображение зависимостей файла
- Минимальный CLI и JSON-вывод
- Модульный каркас и контракт инспектора

### Не входит (см. deferred)

- TUI и графические интерфейсы
- Модификация / рефакторинг кода и AI-операции
- Полноценный multi-language анализ
- Обязательный LSP / Tree-sitter
- Monorepo build-system и релизы
- Глубокий quality / visualization / validation

Подробнее: [mvp-scope.md](../20-features/mvp-scope.md), [handbook/roadmap](../../handbook/roadmap/README.md).
